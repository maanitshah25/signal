# Signal – Research Intelligence Tracker

A Chrome sidebar extension that lets you bookmark any researcher or lab 
with one click and receive an automatic intelligence feed of papers, 
citations, grants, and patents — powered by the TinyFish Mino API.

## Install
1. Clone this repo
2. Go to `chrome://extensions`
3. Enable Developer Mode
4. Click Load Unpacked → select this folder

## How it works
- Navigate to any researcher page (Google Scholar or university profile)
- Signal auto-detects the researcher in the sidebar
- Click **+ Track** to start monitoring
- TinyFish agents search for papers, citation spikes, grants & patents
- Daily background checks notify you when new papers are published
